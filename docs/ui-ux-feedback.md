# Agent Mesh UI/UX Core Feedback & Testing Guidelines

본 문서는 **에이전트 메시 플랫폼(Agent Mesh Platform) 프론트엔드 화면 개발 및 UI/UX 테스트 시 상시 검증해야 하는 핵심 원칙과 사용자 피드백 누적 체크리스트**입니다.

모든 화면 테스트 및 기능 구현 시 본 가이드라인의 요구사항이 충족되었는지 필수적으로 교차 검증해야 합니다.

---

## 📌 UI/UX 피드백 누적 체크리스트 (UI/UX Feedback Register)

### 1. 명칭 및 뷰어 아키텍처 원칙
- **명칭 표준화**: 
  - 과거 명칭 "스웜 갤럭시 토폴로지" ➔ **"에이전트 토폴로지"**로 메뉴, 헤더, 서브 내비게이션 일관 적용.
- **인터랙티브 뷰어 이식 및 테마 일관성**:
  - 10단계 스케일 시뮬레이터(Stage 1~10), 오비탈 은하계 원형 배치, 캐릭터 아바타(핀둥이, 핀자, 아름이), 우측 노드 인스펙터, 빠른 메시지 발송(`Send Message ✈`) 기능 완전 보존.
  - `#F8FAFC` 오리지널 라이트 캔버스 테마와 시인성 높은 은하계 팔레트 유지.

### 2. 캔버스 줌 & 팬 (Zoom & Pan) 정밀 제어
- **마우스 커서 중심 줌 (Cursor-Centered Mathematical Zoom)**:
  - 휠 스크롤 줌 시 화면 중앙이 아닌 **마우스 커서가 위치한 월드 좌표(`worldX, worldY`)를 정확히 고정**하여 확대/축소되어야 함.
- **캔버스 전용 이벤트 격리 (Event Isolation)**:
  - 캔버스 영역에서의 휠 조작/핀치 줌이 브라우저 기본 페이지 스크롤과 간섭되지 않도록 `{ passive: false }` 및 `e.preventDefault()` 적용.
- **5% 마진 피팅 (Fit-to-Screen) & 줌아웃 하한선 (Min-Zoom Lock)**:
  - 모든 그려진 엔티티(은하계, 노드, 게이트웨이, 라벨)의 바운딩 박스를 실시간 계산하여 **타이트한 5% 마진(`margin = entitySize * 0.05`)**으로 화면에 꽉 차게 렌더링.
  - HUD 우측 버튼은 아이콘이 아닌 **`Fit` 텍스트 버튼**으로 명확히 표기.
  - **최대 축소 한계(Min Scale)를 `fitScale`로 잠금**: 줌아웃 시 그래프가 허공 속으로 점처럼 작아져 과도한 여백이 발생하는 현상을 원천 방지.

### 3. 미니맵 (Minimap) 렌더링 및 인터랙션
- **스마트 플로팅 렌즈 오버레이 (Smart Floating Lens)**:
  - **Fit(전체 조망) 상태**: 미니맵 전체를 덮는 불필요한 박스나 파란 테두리를 표시하지 않고 순수 클러스터 조망 미니맵으로 깔끔하게 렌더링.
  - **줌인(확대) 상태 (`scale > fitScale`)**: 현재 뷰포트 시야를 나타내는 부드러운 블루 플로팅 렌즈(`background: rgba(37, 99, 235, 0.18)`)가 미니맵 위에 자연스럽게 활성화.
- **미니맵 클릭 & 드래그 실시간 탐색**:
  - 미니맵을 클릭하거나 드래그할 때 캔버스 시야가 해당 위치로 즉시 이동.
  - 뷰포트 렌즈가 미니맵 컨테이너 테두리를 절대로 침범하거나 벗어나지 않도록 클램핑.

### 4. 조작성 및 드래그 안전망 (Drag & Selection Stability)
- **포인터 캡처 (Pointer Capture) & 텍스트 선택 방지**:
  - 캔버스 드래그 팬 조작 시 `setPointerCapture`를 적용하여 마우스가 캔버스 밖(사이드바, 헤더)으로 나가더라도 사이드바 텍스트가 파랗게 선택되는 현상 원천 차단.
  - 캔버스 밖에서 마우스 버튼을 떼더라도 드래그가 정상 해제되도록 글로벌 릴리즈 안전망(`window.pointerup` / `mouseup`) 보장.
  - 드래그 종료 후 커서가 캔버스로 돌아왔을 때 클릭 없이 마우스 이동만으로 캔버스가 스크롤되는 고착 버그 방지.

### 5. 노드 및 피어 인터랙션 (Camera Flight Animation)
- **연결된 피어(Connected Peers) 선택 시 부드러운 비행 애니메이션**:
  - 우측 인스펙터 패널의 연결된 피어 버튼(`🔗 peer-name`) 클릭 시, 해당 노드로 **450ms 3차 감속 곡선(Cubic Ease-Out) 카메라 비행 애니메이션** 실행.
- **스마트 오프셋 프레이밍 (Smart Offset Framing)**:
  - 우측에 320px 인스펙터 드로어가 열려 있을 때, 목표 노드가 정보 창에 가려지지 않도록 **화면의 42% X 지점(좌측 중심)으로 스마트 오프셋 센터링**.

## 🧪 화면 테스트 시 필수 검증 체크리스트 (QA Test Matrix)

| 검증 항목 | 테스트 방법 | 기대 결과 |
| :--- | :--- | :--- |
| **커서 기준 줌** | 특정 은하계 노드 위에 커서를 올리고 휠 확대/축소 | 커서 아래의 노드 위치가 화면에서 튀지 않고 고정된 채 부드럽게 줌 인/아웃 |
| **최대 축소 한계** | 휠을 계속 아래로 굴려 최대 줌아웃 | 5% 여백 핏 스케일 이하로 축소되지 않고 화면에 꽉 찬 상태 유지 |
| **Fit 버튼 동작** | `Fit` 버튼 클릭 | 전체 10개 스웜(또는 현재 단계 스웜)이 5% 여백으로 정중앙에 정렬 |
| **미니맵 렌즈 가시성** | Fit 상태 vs 줌인 상태 비교 | Fit 상태에서는 렌즈 숨김, 줌인 시에만 정확한 크기의 플로팅 렌즈 오버레이 표시 |
| **캔버스 밖 드래그** | 캔버스를 클릭한 채 사이드바/브라우저 창 밖으로 드래그 후 릴리즈 | 사이드바 텍스트가 선택되지 않고, 캔버스로 커서 복귀 시 드래그 락 없이 정상 정지 |
| **연결된 피어 클릭** | 노드 선택 ➔ 인스펙터 내 피어 뱃지 클릭 | 부드러운 Ease-Out 애니메이션으로 시야가 날아가며 좌측 중심(42% 지점)에 안착 |
