Contracts v0.10.0 RBAC 9대 권한(Capability) 및 화면 매핑

Agent Mesh 플랫폼은 권한 세분화(Least Privilege) 원칙에 따라 9개의 불변 역량 토큰으로 관리자 액션을 게이트합니다.

key.approve Strict Gate
에이전트 공개키 승인/거부/폐기
POST /api/v1/admin/keys/approve, deny, revoke
GET /api/v1/admin/agents/owned (소유 에이전트 승인 큐)
preview/tenant/key-approvals.html
key.propose Agent Auth
에이전트 신규 키 제안 및 로테이션
POST /api/v1/agents (키 제안 포함)
GET /api/v1/agents/{identity}/keys
preview/creator/agent-register.html
agent.provision Admin Auth
신원 프로비저닝 및 Teardown
POST /api/v1/agents, DELETE /api/v1/admin/agents/{identity}
preview/creator/agent-teardown.html
group.egress Tenant Gate
스웜 그룹 간 이그레스 정책 제어
POST /api/v1/admin/groups/{group_id}/egress, DELETE /api/v1/admin/groups/{group_id}/egress/{to_group}
preview/tenant/egress-acl.html
audit.read.content Critical Gate
메시지 본문 열람 감사 권한
GET /api/v1/audit/events (본문 미보유 시 [content withheld ...]로 리댁션)
preview/tenant/participant-audits.html
pairing.generate RFC 8628
RFC 8628 페어링 코드 발급
POST /api/v1/admin/pairing-codes (단회용 Crockford Base32 8자)
preview/tenant/pairing-codes.html
pairing.redeem Public API
페어링 코드 교환 및 소유권 등록
POST /api/v1/pairing-codes/redeem (무인증 허용, 단회 사용 후 소멸)
preview/tenant/pairing-codes.html
inbox.lease Socketless
인박스 원자적 임대(Lease) & Ack
POST /api/v1/inbox (ack_ids + lease_seconds)
preview/creator/lease-queue.html
message.send Signed / Proxy
메시지 전송 및 아웃박스 적재
POST /api/v1/outbox, POST /api/v1/messages (JWT 프록시 전송)
preview/creator/playground.html
